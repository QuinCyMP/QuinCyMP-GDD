## 1. Faucet / sink — โครงเดียวที่ต้องเข้าใจให้ทะลุ

เศรษฐกิจเกมคือถังน้ำ **faucet** คือท่อน้ำเข้า **sink** คือท่อน้ำออก
ถ้าน้ำเข้ามากกว่าออกอย่างต่อเนื่อง เงินเฟ้อจนระบบพัง — และมันจะเกิดเสมอถ้าไม่ได้ออกแบบไว้

```
อัตราเงินเฟ้อ = (Σ faucet ต่อผู้เล่นต่อชั่วโมง − Σ sink ต่อผู้เล่นต่อชั่วโมง) ÷ เงินเฉลี่ยที่ถืออยู่
```

เป้าหมายที่ใช้ได้จริง: **faucet − sink ≈ 0 ถึง +5% ต่อเดือน**
บวกเล็กน้อยดีกว่าศูนย์พอดี เพราะผู้เล่นใหม่ต้องมีเงินไหลเข้าระบบ แต่เกิน 10% ต่อเดือน
ราคาสินค้าจะวิ่งหนีผู้เล่นใหม่จนเข้าเกมไม่ได้

**ตารางที่ต้องมีในเอกสาร:**

| Faucet (เงินเข้า) | g/ชม. | | Sink (เงินออก) | g/ชม. |
|---|---|---|---|---|
| ล่า mob ปกติ | 800 | | ซ่อมอุปกรณ์ | 260 |
| ขายของให้ NPC | 300 | | ค่าเดินทาง | 90 |
| เควสรายวัน | 400 | | ค่าธรรมเนียมตลาด (5%) | 180 |
| **รวม** | **1,500** | | ยา/เสบียง | 350 |
| | | | ค่าเช่าที่ดิน | 120 |
| | | | ค่า crafting ที่ล้มเหลว | 400 |
| | | | **รวม** | **1,400** |

ตัวเลขข้างบนเป็น**ตัวอย่างรูปแบบ** ไม่ใช่ค่าที่ควรลอก — ใส่ตัวเลขของเกมจริงลงไป

**Sink ที่ได้ผลจริง เรียงตามประสิทธิภาพ:**
1. **ความเสื่อมสภาพ / การซ่อม** — ดูดเงินต่อเนื่องตามการเล่น ไม่รู้สึกเป็นภาษี
2. **ค่าธรรมเนียมธุรกรรม** — ยิ่งเศรษฐกิจคึกยิ่งดูดมาก ปรับสมดุลตัวเอง
3. **ของสิ้นเปลือง** — ยา อาหาร กระสุน เสริมความแรงชั่วคราว
4. **ความล้มเหลวในการ craft/upgrade** — ดูดเงินก้อนใหญ่ แต่ต้องระวังความรู้สึกผู้เล่น
5. **ของสถานะที่ไม่ให้พลัง** — cosmetic, ที่อยู่อาศัย, ตำแหน่ง — sink ที่ไม่กระทบบาลานซ์เลย

**Sink ที่ไม่ได้ผล:** ของที่ซื้อครั้งเดียวจบ (ดูดครั้งเดียวแล้วหยุด),
อะไรก็ตามที่ผู้เล่นหลีกเลี่ยงได้ด้วยการไม่ทำกิจกรรมนั้น

## 2. Drop rate และเวลาที่ต้องใช้

```
เวลาเฉลี่ยจนได้ของ  E[t] = เวลาต่อครั้ง ÷ อัตราดรอป
เวลาจนได้ของที่ความมั่นใจ 90%   t₉₀ = เวลาต่อครั้ง × ln(0.10) ÷ ln(1 − p)
```

ตัวอย่าง: ดรอป 1% ใช้เวลาฆ่าตัวละ 90 วินาที
- เฉลี่ย: 90 ÷ 0.01 = 9,000 วินาที = **2.5 ชั่วโมง**
- 90% ของผู้เล่นได้ภายใน: 90 × ln(0.1)/ln(0.99) = **5.7 ชั่วโมง**
- แต่ผู้เล่น 1% ที่โชคร้ายที่สุดยังไม่ได้หลัง **11.5 ชั่วโมง** — คนกลุ่มนี้คือคนที่โพสต์ด่าในฟอรั่ม

**กฎที่ควรเขียนในเอกสาร:** ถ้า t₉₀ เกิน 10 ชั่วโมง ต้องมี **pity system**
(ตัวนับที่การันตีว่าจะได้ภายใน N ครั้ง) ไม่งั้นความรู้สึกไม่เป็นธรรมจะทำลายความไว้ใจ

```
Pity: หลังครั้งที่ N อัตราดรอปเพิ่มขึ้นทีละ x% ต่อครั้ง จนถึง 100% ที่ครั้งที่ M
```

## 3. XP curve

สามแบบที่ใช้กันจริง — ใส่ผลลัพธ์เป็น `data/xp-curve.csv`:

| แบบ | สูตร | ความรู้สึก |
|---|---|---|
| Linear | `XP(n) = a × n` | เลเวลหลังไวเกิน ไม่มีน้ำหนัก |
| Polynomial | `XP(n) = a × n^b` (b ≈ 1.5–2.5) | **ค่าตั้งต้นที่ดีที่สุด** ก้าวหน้าสม่ำเสมอ |
| Exponential | `XP(n) = a × r^n` (r ≈ 1.1–1.2) | เลเวลท้ายกลายเป็นกำแพง ต้องระวัง |

ตรวจด้วยการแปลงเป็น**เวลา**เสมอ ไม่ใช่ดูแต่ตัวเลข XP:
```
ชั่วโมงต่อเลเวล(n) = XP(n) ÷ (XP ที่หาได้ต่อชั่วโมง ณ เลเวลนั้น)
```
รูปทรงที่ดี: เลเวลต้น ๆ ไม่กี่นาที กลางเกม 1–3 ชั่วโมง ปลายเกม 5–15 ชั่วโมง
ถ้าเลเวลสุดท้ายใช้เวลาเกิน 40 ชั่วโมงต่อเลเวล ต้องมีเป้าหมายรองระหว่างทาง

## 4. Power curve และบาลานซ์

```
Power ≈ (ดาเมจต่อวินาที) × (เลือดที่ทนได้)
```
ทั้งสองฝั่งคูณกัน — เพิ่มดาเมจ 20% และเลือด 20% = แรงขึ้น 44% ไม่ใช่ 20%
นี่คือสาเหตุที่เกียร์ที่ให้ทั้งสองอย่างทำให้บาลานซ์ระเบิดเร็วกว่าที่คิด

**อัตราส่วนที่ต้องระบุในเอกสาร:**
- พลังผู้เล่น endgame ÷ พลังผู้เล่นใหม่ — ค่าที่ใช้ได้ **10× ถึง 50×**
  เกิน 100× แปลว่าผู้เล่นใหม่กับเก่าเล่นด้วยกันไม่ได้เลย ซึ่งฆ่าความเป็น MMO
- ช่องว่างพลังระหว่าง tier เกียร์ที่ติดกัน — **10–20%** ต่อ tier
- ช่วงเลเวลที่ยังจับกลุ่มเล่นด้วยกันได้ — ต้องระบุ เพราะกำหนดว่าเพื่อนสองคนต่างเลเวลเล่นด้วยกันได้ไหม

## 5. ตลาดผู้เล่นและสภาพคล่อง

ถ้าออกแบบให้ผู้เล่นค้าขายกันเอง ต้องตอบ:

| คำถาม | ทำไมสำคัญ |
|---|---|
| ของผูกกับตัวละครไหม (bind on pickup) | ผูก = ไม่มีตลาด, ไม่ผูก = ตลาดมีชีวิตแต่บอทมา |
| ต้องมีผู้เล่นกี่คนตลาดถึงมีสภาพคล่อง | ต่ำกว่า ~500 CCU ตลาดเสรีมักไม่ทำงาน ต้องมี NPC ประคอง |
| ซื้อขายที่ไหน | ประกาศเอง (ช้า เป็นสังคม) / auction house (เร็ว ไร้ตัวตน) — เปลี่ยนวัฒนธรรมเกมทั้งหมด |
| ค่าธรรมเนียมเท่าไร | คือ sink หลัก 3–8% เป็นช่วงปกติ |
| ของหายากมีจำนวนจำกัดจริงไหม | ของที่ผลิตได้ไม่จำกัดจะราคาตกเป็นศูนย์เสมอ |

**กฎสำหรับทีมเล็ก:** ตลาดเสรีต้องการมวลวิกฤต ถ้าตั้งเป้า CCU ต่ำกว่า 500
ให้ออกแบบเป็นตลาดกึ่ง NPC (NPC รับซื้อที่ราคาพื้น) ไม่งั้นผู้เล่นจะขายของไม่ออกและเลิกเล่น

## 6. เวลาเป็นสกุลเงินจริง

ทุกอย่างในเกมมีราคาเป็น**ชั่วโมงของผู้เล่น** เขียนตารางนี้ในเอกสารเสมอ:

| สิ่งของ | ชั่วโมงที่ต้องใช้ | ผู้เล่นแบบไหนเข้าถึงได้ |
|---|---|---|
| เกียร์ครบชุดระดับกลาง | 15 ชม. | ทุกคน |
| เกียร์ครบชุด endgame | 120 ชม. | คนเล่นประจำ |
| ไอเทมหายากสุด | 400+ ชม. | 2% บนสุด |

แล้วเทียบกับ **เวลาเล่นจริงของผู้เล่นเป้าหมาย** — ถ้าผู้เล่นเป้าหมายเล่น 6 ชม./สัปดาห์
เกียร์ endgame 120 ชม. = 5 เดือน ซึ่งอาจนานเกินไปหรือกำลังดี แต่ต้องเป็นการ**ตัดสินใจ**
ไม่ใช่ผลข้างเคียงที่ไม่ได้ตั้งใจ
